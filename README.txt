Бот CRMP (КРМП) для ВКонтакте
=============================

ADMINS=854071888 в .env — главные админы (нельзя снять через бота).

Функции игрока:
- Регистрация / ЛК / профиль
- Работа, ежедневка, магазин, инвентарь, перевод, топ
- Голосования
- Предложить идею

Админ:
- Заявки, игроки, статистика, баны
- Управление админами бота: админдобавить / админубрать
- Идеи (принять / отклонить / сделано)
- Голосования: голосование Вопрос | да | нет
- Экономика и модерация с уведомлениями

Запуск:
pip install -r requirements.txt
python bot.py
