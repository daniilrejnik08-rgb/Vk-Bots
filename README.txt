Prp Games — бот ВКонтакте (регистрация + личный кабинет)
=========================================================

1. Установи Python 3.10 или новее.

2. Открой папку проекта в командной строке и установи библиотеки:
   pip install -r requirements.txt

3. Скопируй файл .env.example и переименуй копию в .env
   Заполни:
   TOKEN=токен_сообщества_вк
   ADMINS=твой_цифровой_id_вк

   Как узнать свой ID: зайди на https://vk.com/id0 или в настройки профиля.

4. В сообществе ВК:
   - Управление -> Настройки -> Работа с API
   - Создай ключ с правами на сообщения
   - Включи Long Poll API (последняя версия)
   - Событие message_new
   - Включи сообщения сообщества

5. Запуск:
   python bot.py

Команды игрока:
- Начать / меню
- Регистрация
- Личный кабинет
- Мой профиль
- Информация

Команды админа:
- Админ-панель
- Заявки (одобрить / отклонить кнопками)
- Игроки
