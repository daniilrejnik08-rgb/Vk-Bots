Prp Games — бот с расширенной админкой
======================================

КАК СДЕЛАТЬ СЕБЯ АДМИНОМ
------------------------
1. Узнай свой ID ВК (цифры из vk.com/idXXXXXX)
2. В .env или переменных хостинга:
   ADMINS=ТВОЙ_ID

   Несколько админов через запятую:
   ADMINS=111111,222222

3. Перезапусти бота.
4. Напиши «меню» — должна появиться кнопка «Админ-панель».

Если регистрируешься сам как админ — заявка одобряется сразу.
